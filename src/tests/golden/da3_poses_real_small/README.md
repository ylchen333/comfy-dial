# DA3 poses of REAL LTX takes (small)

These are Depth Anything 3 (small) poses recovered from real LTX-2.5 takes (`dollyzoom_take.mp4`, `dolly_control_take.mp4`), NOT from the rendered golden clips. File names are the golden-clip names the poses should be scored against (`dolly_zoom_5to3`, `dolly_5to3`). Every 4th frame (31 frames), fps 25, t = index/25.
